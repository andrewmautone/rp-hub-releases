# RP Pedidos — downloads

Hub de pedidos do **Roleplay Burger** para Windows: junta iFood, 99, Keeta e o site num quadro só e imprime a comanda na impressora térmica.

## Instalar

1. Baixe o **`rp-hub.exe`** da [última versão](https://github.com/andrewmautone/rp-hub-releases/releases/latest).
2. Coloque numa pasta fixa (ex.: `C:\RP Pedidos\`) e abra.
3. Entre com o login do painel do rpstock.

O app abre junto com o Windows e se atualiza sozinho (só com o quadro recolhido e sem pedido em andamento). Para atualizar na hora: engrenagem → **Procurar atualização**.

Este repositório só guarda as versões publicadas. Cada versão traz um `latest.json` com o SHA-256 e a assinatura do executável; o app recusa qualquer arquivo que não tenha sido assinado pela chave do Roleplay.
